# Assets

## Asset policy

Prefer original assets made specifically for this portfolio.

Allowed source priorities:

1. self-created assets
2. CC0 assets
3. permissively licensed open-source assets

Poly Haven CC0 assets are acceptable where appropriate.

Do not use random internet assets without confirming licensing.

## 3D

Signature models should preferably be custom-built in Blender.

Examples:
- Amine Core
- compute modules
- network hardware
- server infrastructure
- automation nodes

## Audio

Prefer original sound design.

Simple interface sounds may be synthesized or created specifically for
the project.

Do not use unverified commercial sound packs.

## Fonts

Only use fonts that can legally be self-hosted and used in this portfolio
without payment.
