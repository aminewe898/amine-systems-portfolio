# Portfolio Art Direction

Design for a premium technical/industrial experience.

## Visual target

The experience should feel influenced by:
- premium product storytelling
- industrial design
- engineering visualization
- creative WebGL studios
- precision hardware interfaces

Do not directly copy an existing site.

The design should communicate engineering capability rather than decorate
the page with arbitrary futuristic effects.

## Palette

Base direction:

- near black: #050609
- surface: #0A0D12
- elevated: #10151D
- primary cobalt: #246BFD
- electric blue: #59A3FF
- ice: #DCE7F7
- primary text: #F4F7FB
- muted text: #8792A6

Treat these as design tokens, not a requirement to use every color at once.

Use blue as an accent, not as wallpaper.

## Materials

Preferred visual material language:

- black anodized aluminium
- dark graphite
- gunmetal
- brushed metal
- smoked glass
- subtle emissive circuitry
- high-quality studio reflections

Avoid cheap-looking transparency or excessive glassmorphism.

## Typography

Typography should do much of the visual work.

Prefer:
- strong hierarchy
- large editorial/technical titles
- clean grotesk/sans typography
- monospace only where technical context benefits from it
- deliberate spacing

Do not make every label monospace just because the project is technical.

## 3D

Every major 3D object should have a reason to exist.

Good:
- compute core representing systems
- network topology representing networking
- server rack representing infrastructure
- physical workflow modules representing automation
- exploded hardware representing repair/hardware skills

Bad:
- random torus
- floating balls
- decorative blob
- meaningless chrome sculpture

Prefer premium product lighting and readable silhouettes.

## Motion

Motion should communicate:
- weight
- direction
- hierarchy
- cause and effect

Use restrained springs, inertia and physical-feeling timing.

Avoid animating every element.

Reserve large cinematic movement for important transitions.

## Sound

Sound should be subtle and tactile.

Suitable categories:
- mechanical click
- soft relay
- servo
- low impact
- data pulse
- controlled electrical startup
- terminal tick

Never make ordinary hover interactions loud.

Sound must be optional.

## UI review

Before accepting a visual section ask:

1. Does it communicate something real?
2. Does the layout still work without the 3D layer?
3. Is the typography strong enough?
4. Is animation improving comprehension?
5. Does it resemble a generic AI-generated landing page?
6. Is there anything decorative that can be removed?
7. Does it still feel premium when motion is disabled?

If the answer to #5 is yes, redesign it.
